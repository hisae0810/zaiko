🎯 総合評価について

📌 通常月平均回転率を採用する理由:
  • ✅ 棚卸月(3月・10月)を除外:月末在庫が意図的に少なくなるため、実力を正しく反映しない
  • ✅ 特殊案件(100回転超)の影響を軽減:病院新築などの一時的な大型案件を考慮
  • ✅ 安定性も評価:通常業務での継続的な在庫管理能力を測定
  • ✅ 比較可能性の向上:営業所間の公平な評価が可能

💡 在庫回転率とキャッシュフローの関係

在庫回転率 = 当月出庫数 ÷ 平均在庫数(前月末在庫 + 月末在庫)÷ 2
💰 なぜ在庫回転率が重要なのか?
在庫は「仕入先に支払済みだが、まだ売上として回収できていないお金」です。
在庫回転率が低い = 資金が長期間固定される = キャッシュフローが悪化します。

🎯 評価基準

  • 🟢 月間30回以上 = 最優秀
    約1日で在庫が入れ替わる。資金効率が極めて良い。
  • 🟡 月間20〜30回 = 優秀
    約1〜1.5日で在庫が入れ替わる。高水準の在庫管理。
  • 🟠 月間15〜20回 = 標準
    約1.5〜2日で在庫が入れ替わる。標準的な管理レベル。
  • 🔴 月間15回未満 = 要改善
    2日以上在庫を保有。改善の余地あり。

💸 資金繰りへの影響

  • 本社への支払
    20日締め → 4ヶ月後払い(120日猶予)
  • ディーラーからの入金
    優良:60日後、医薬品卸:180日後
  • 在庫保管が長い
    → 資金が固定 → 他の取引に使えない

✅ 実践ポイント

  • ⚡ 素早い出荷・納品
  • 🏆 優良ディーラー優先
  • 🚨 滞留在庫に注意
